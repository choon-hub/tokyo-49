# 辞書・地図データの出典と作り直し方

アプリに同梱している辞書（`assets/dict/dict.db`）と地図（`src/data/map-shapes.json`）は、公開データから
`scripts/build-data/` のスクリプトで生成したものです。アプリ本体は通信せず、同梱した生成物だけを使います。

## 出典

| データ | 出典 | 使い道 | 利用条件 |
|---|---|---|---|
| 行政区域 | 国土交通省 国土数値情報「行政区域データ」（N03、東京都、2025年1月1日時点） | 駅の区市判定、地図の形 | [国土数値情報 利用規約](https://nlftp.mlit.go.jp/ksj/other/agreement.html)。出典の明記が必要 |
| 駅 | 国土交通省 国土数値情報「鉄道データ」（N02、2024年度） | 駅名・路線名・駅の位置 | 同上。データごとの利用条件は配布ページで確認する |
| 町域 | 日本郵便「郵便番号データ」（KEN_ALL、UTF-8 版） | 町域名・読み・区市コード | [郵便番号データの説明](https://www.post.japanpost.jp/zipcode/dl/readme.html)。自由に配布・利用できる |
| 駅の読み | [Wikidata](https://www.wikidata.org/)（読み仮名 P1814、座標 P625） | 駅名の読み（N02 に読みが無いため） | CC0 |

- 「国土数値情報（行政区域データ・鉄道データ）」（国土交通省）を加工して作成しています。
- 駅データ.jp などの会員登録が要るデータは使っていません。
- 個人利用のアプリを前提に確認しています。**ストア公開や商用利用をする前に、各配布ページの最新の利用条件を確認し直してください。**

## 作り直し方

Node.js 22.5 以上（`node:sqlite` を使う。CI と同じ Node 24 を推奨）で実行します。

```sh
npm run build:data              # 無い元データだけ取得して生成
npm run build:data -- --force   # 元データを取り直して生成
npm run build:data -- --report  # 読みの付かなかった駅なども表示
```

- 元データは `scripts/build-data/.cache/` に保存します（コミットしません）。取得元の URL と年度は `scripts/build-data/download.mjs` に固定しています。
- 生成物（`assets/dict/dict.db`、`src/data/dict-version.ts`、`src/data/map-shapes.json`）はコミットします。
- **辞書の中身が変わったら、`scripts/build-data/build.mjs` の `DICT_VERSION` を上げます。** 端末内の辞書は、同梱版の番号が大きいときだけ差し替わります。上げ忘れるとスクリプトが失敗します。
- 49区市のマスタは `src/data/municipalities.ts` が正です。N03 の区市名と食い違うとスクリプトが失敗します。

## 生成のルール

### 駅（`stations`）
- 駅の代表点（N02 の駅の線分の頂点の平均）を、簡略化していない N03 のポリゴンで判定し、49区市に入る駅だけを残す。
- 同じ駅名で同じ区市のもの（事業者・路線違い）は1件にまとめ、路線名を `lines` に並べる。
- 同じ駅名で区市が分かれるもの（区境の駅）は、`scripts/build-data/overrides.json` の `stations`（駅名 → 区市コード）で1つに決める。
  未指定のものが残ると、スクリプトの最後に一覧が出る。
- 駅名は NFKC 正規化して格納する（検索の入力も NFKC にそろえるため）。「ヶ／ケ」などの表記ゆれはそろえない。
- 読みは Wikidata の同名の駅・停留場のうち、3km 以内で最も近いものを使う。付かなかった駅は
  `overrides.json` の `stationKana`（駅名 → ひらがな）で補う。読みが空の駅は、名前でだけ検索に掛かる。

現在の `overrides.json`:

| 駅 | 確定した区市 | 理由 |
|---|---|---|
| 新宿 | 新宿区 | JR・私鉄の駅本体が新宿区。一部の路線が渋谷区にかかる |
| 四ツ谷 | 新宿区 | 駅の所在地が新宿区四谷 |
| 市ヶ谷 / 御茶ノ水 / 水道橋 / 飯田橋 | 千代田区 | JR の駅の所在地 |
| 溜池山王 | 千代田区 | 駅の所在地が千代田区永田町 |
| 日暮里 | 荒川区 | 駅の所在地が荒川区西日暮里 |
| 拝島 | 昭島市 | JR の駅の所在地 |
| 玉川上水 | 立川市 | 西武線の駅の所在地 |

### 町域（`towns`）
- KEN_ALL のうち、区市コードが49区市の行だけを使う。
- 「以下に掲載がない場合」「…の次に番地がくる場合」「…一円」、ビルの階ごとの行（`（１階）` など）は除く。
- 町域名の括弧書き（`（次のビルを除く）` など）は取り除き、括弧が複数行に分かれた続きの行は読み飛ばす。
- 町域名＋区市コードで重複を除く。同名の町域が複数の区市にある場合（本町など）は、区市ごとに1行ずつ持つ。
- 読みはひらがなにする。

### 地図（`map-shapes.json`）
- N03 を区市コードごとにまとめ、[mapshaper](https://github.com/mbloch/mapshaper) で境界を共有したまま簡略化する。
- 0.2km² 未満の飛び地（埋立地の破片など）は落とす。町・村・島しょ部は元から含めない。
- 経度方向を cos(緯度) で縮めた平面座標に変換し、幅を 1000 にそろえる。`wardsBounds` は23区の外接矩形（初期表示用）。
- 簡略化の強さは `build.mjs` の `-simplify` の割合で調整する。上げると滑らかになり、データは重くなる。
